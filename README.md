## 🧑‍💻 关于我

我是一名专注于 **AI 应用开发** 和 **工业数据智能** 的研究生，核心方向是把大语言模型真正用到工业场景里——不是做 demo，而是跑在生产环境里解决问题。

目前在做的两件事：

🔹 **NL2SQL 查询引擎** — 让工程师用自然语言查工业数据库，不用写 SQL，准确率 > 90%
🔹 **空分装置智能诊断** — 用 LangGraph 构建 Agent 流程，自动诊断设备异常并给出优化建议

从数据接入、模型部署、RAG 检索到前后端交付，我能独立走完 **研究 → 产品 → 上线** 的全流程。

## 💼 核心项目

### 基于大模型的工业数据查询引擎
> 浙江大学-杭氧联合研发项目 · 独立完成

- 设计"意图识别→任务分解→Schema Linking→SQL生成→执行反馈"多阶段推理链路
- Qwen 模型私有化部署 + PostgreSQL 工业数据库对接
- 融合 RAG 检索增强、多轮对话与图表展示
- 集成 OAuth2 + JWT 分级权限控制
- **成果：复杂查询准确率 > 90%，已稳定试运行**

### 空分装置智能诊断与优化决策系统
> 当前在研项目 · 独立进行

- 基于 LangGraph 设计节点化 Agent 流程
- 构建"数据质量门禁→特征提取→异常识别→证据链推理→优化建议"分层诊断链路
- 引入领域知识库 RAG 检索 + 机理约束推理
